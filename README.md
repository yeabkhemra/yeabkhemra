### Building practical machine learning and web applications

I work on projects that connect data and machine learning with useful, accessible applications. My work includes computer vision for agriculture, air-quality forecasting, and web application development.

## Featured project — Smart Chomka

A Khmer-language agricultural PWA that brings durian leaf classification and farming information into a mobile-friendly interface.

- **Machine learning:** Five-class image classification with EfficientNet-B0; comparisons with ResNet18 and MobileNetV3-Small.
- **Deployment:** ONNX Runtime Web for browser inference and a Vercel-hosted frontend.
- **Application engineering:** Farm profiles, image inspection, disease guides, and a Python/SQLite commerce prototype.
- **Quality:** Backend tests for authentication, checkout, stock handling, and order privacy.

[Explore the repository](https://github.com/yeabkhemra/smart-chomka) · [Open the frontend demo](https://smart-chomka.vercel.app/) · [Read the project report](https://github.com/yeabkhemra/smart-chomka/blob/main/docs/PROJECT_REPORT.md)

The shared-account and commerce backend currently runs locally. The repository documents the model's reported results and current limitations.
